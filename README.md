# SQL Business Analysis Project

## 📌 Project Overview
This project is a beginner-friendly SQL mini project created as part of a structured Data Analyst learning plan.
The goal of this project is to analyze a simple business dataset using SQL queries and understand how SQL is used in real-world business analysis.

---

## 🗂 Dataset Description
The project uses three tables:

### 1. Customers
Stores customer details such as name and city.

### 2. Products
Stores product information and price.

### 3. Orders
Stores order details including customer, product, and quantity ordered.

These tables are connected using primary keys and foreign keys.

## 📊 Business Analysis Queries Performed

1. View all orders to understand raw data  
2. Display customer-wise orders using INNER JOIN  
3. Show product-wise quantity ordered  
4. Calculate total quantity sold per product  
5. Calculate revenue per order  
6. Analyze city-wise total revenue  

These queries help answer real business questions such as:
- Which products sell the most?
- Which city generates more revenue?
- How much revenue does each order generate?

---

## 📈 Key Business Questions

The SQL queries are designed to answer:

- Which products have the highest quantity sold?
- Which cities generate the most revenue?
- What is the revenue generated by each order?
- How do customers, products, and orders relate to each other?
